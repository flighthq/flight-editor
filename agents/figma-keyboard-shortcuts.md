# Figma Keyboard Shortcuts

Authoritative reference for all keyboard shortcuts in Figma (circa 2024–2025). Mac users substitute Cmd for Ctrl and Option for Alt unless noted.

## Essential

| Shortcut | Action |
|----------|--------|
| Ctrl+/ or Ctrl+P | Quick Actions — search any command, tool, plugin, or setting |

## Comparison: Move (V) vs Scale (K)

Both tools select and transform objects. The key difference:

| Feature | Move (V) | Scale (K) |
|---------|----------|-----------|
| Stroke width on resize | Unchanged | Scales |
| Corner radius on resize | Unchanged | Scales |
| Text size on resize | Unchanged (reflows) | Scales |
| Effects on resize | Unchanged | Scales |
| Constraints | Applied | Ignored |
| Best for | Layout, repositioning | Uniform scaling of visual elements |
