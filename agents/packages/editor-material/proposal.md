# Editor Material Proposal

Ownership: Flight Editor authoring over Flight materials and renderer capabilities.

Provide shared material assets and inline materials, slot assignment, typed schema-driven property editing, textures, presets, duplicate/detach, preview thumbnails, usage queries, and diagnostics. Do not reimplement shading or renderer feature detection.

Acceptance requires reference versus literal semantics, multiple slots, texture color space/sampling, missing assets, unsupported properties, renderer differences, clipboard dependency transfer, undo, and serialization.
