# Editor Prototype Proposal

Ownership: Flight Editor authoring over Flight flow/statechart/runtime primitives.

Model named flows, home targets, triggers, conditions, actions, destinations, transitions, overlays, scroll targets, variable writes, and explicit auto-animation mappings as a stable authored graph. Own wire gestures, commands, graph selection, validation, inspector metadata, and preview compilation. Wires are presentation only.

Support Spline-like named object states as typed property sets compiled to Flight statechart/animation primitives; active state remains runtime state.

Acceptance requires reconnect/cancel/undo, broken targets, nested components, multiple interactions, typed conditions and variables, navigation history, stale preview revisions, deterministic compilation, and YAML round trips.
