# Editor Physics Authoring Proposal

Ownership: Flight Editor over Flight physics2d/physics3d. Conditional on physics authoring being a product goal.

Contribute body, collider, material, joint, layer/filter, and world properties; creation/edit commands; validated references; debug geometry; and isolated play-mode inspection. Simulation, queries, contacts, solver, and deterministic stepping remain upstream.

Acceptance requires unit/scale conversion, invalid shapes, nested transforms, joint target deletion, debug overlay parity, edit/play isolation, apply-back policy, undo, and serialization.
