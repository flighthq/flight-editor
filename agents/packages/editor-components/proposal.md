# Editor Components Proposal

Ownership: Flight Editor over an upstream reusable-scene-source/instance contract.

Model component source records, placed instances, stable descendant/property overrides, named variants, reset, detach, swap, nesting, and broken sources. Own commands, selection/editing-scope integration, library presentation data, dependency transfer, and diagnostics; do not implement runtime scene instancing locally.

Acceptance requires propagation and override matrices, reordered source descendants, nesting/cycle handling, delete/relink, clipboard, undo, and YAML round trips.
