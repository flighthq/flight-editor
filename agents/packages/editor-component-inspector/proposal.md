# Editor Component Inspector Proposal

Ownership: Flight Editor schema/contribution layer over Flight node and component contracts.

Register typed component schemas, property metadata, defaults, validation, references, add/remove/reset/enable/copy/paste commands, multi-edit applicability, raw read-only inspection, and optional authoring gizmos. This is distinct from reusable component/prefab instances.

Acceptance requires missing/unknown component preservation, schema migration, typed reference validation, mixed values, locked inspector state, command undo, plugin unload, and host inspector parity.
