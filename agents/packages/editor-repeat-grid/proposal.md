# Editor Repeat Grid Proposal

Ownership: Flight Editor, conditional on parametric repeaters being a product goal.

Represent a source subtree, horizontal/vertical repetition, gap, count or extent, and stable per-item content/data overrides. Own resize and gap gestures, selection semantics, detach/expand commands, dependency transfer, and authoring overlays. Runtime expansion may use an upstream layout or instancing primitive.

Acceptance requires resize in both axes, overrides, reorder, detach/undo, clipboard, export, missing data, and deterministic serialization.
